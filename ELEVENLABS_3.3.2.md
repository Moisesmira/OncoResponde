# OncoResponde 3.3.2 — Voces es-ES

Esta versión muestra únicamente voces que ElevenLabs identifica de forma verificable como español de España (`es-ES`) o como español con acento de España/castellano.

La mejor voz femenina disponible aparece marcada como **Recomendada para OncoResponde**. Si no existe una voz femenina es-ES, se recomienda la voz es-ES mejor clasificada.

Si el selector queda vacío, añade desde la Voice Library de ElevenLabs una voz etiquetada como **Spanish — Spain**, **Castilian Spanish** o **es-ES**.
