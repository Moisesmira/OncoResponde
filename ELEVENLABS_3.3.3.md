# OncoResponde 3.3.3 — filtro castellano estricto

Esta versión distingue entre una voz que puede pronunciar español y una voz cuyo acento de origen es español de España.

El selector solo acepta voces cuya ficha de ElevenLabs declare de forma explícita Spain, Spanish (Spain), Castilian Spanish, castellano, peninsular o Madrid. Se excluyen las voces americanas, británicas, australianas y latinoamericanas aunque el modelo multilingüe permita utilizarlas en español.
